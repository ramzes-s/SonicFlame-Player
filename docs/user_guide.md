## 1. Введение

**SonicFlame Player** — это современный аудиоплеер для Windows с тёмным оформлением и широкими возможностями. Он поддерживает форматы MP3, FLAC, M4A/MP4, умеет анализировать аудио для поиска похожих треков, а также позволяет управлять воспроизведением через браузер или мобильное приложение.

### Основные возможности

- Воспроизведение MP3, FLAC, M4A/MP4
- Подбор похожих треков по звучанию (6 аудиохарактеристик + жанр)
- Настраиваемый акцентный цвет (15 пресетов + динамический из обложки)
- Редактор тегов с поиском информации и обложек онлайн
- Библиотека с видом по исполнителям и трекам
- Веб-интерфейс для управления с телефона
- Android-приложение для удалённого управления
- Сворачивание в трей с мини-плеером
- Плагины — расширение функционала сторонними модулями
- Плавное затухание при паузе/воспроизведении (0–5 с)
- Контекстное меню плейлиста (похожие, исполнитель, теги)
- Глобальные медиа-клавиши и SMTC

## 2. Установка и запуск

### Готовая сборка (.exe)

1. Скачайте последнюю версию со [страницы релизов](https://github.com/ramzes-s/SonicFlame-Player/releases) или с [сайта проекта](https://sonicflame.pro)
2. Распакуйте архив в пустую папку
3. Запустите `SonicFlame.exe`

### Запуск из исходного кода

```bash
pip install -r requirements.txt
python main.py
```

### Первый запуск

При первом запуске программа создаёт папку `.cache` в корне проекта (рядом с `main.py`). В ней хранятся:

- **musicplayer.db** — база данных со всей вашей музыкальной библиотекой (настройки, треки, статистика)
- **settings.json** — ваши персональные настройки
- **covers/** — кеш обложек в формате WebP
- **artist_collages/** — коллажи исполнителей для библиотеки

**Самое важное после первого запуска** — указать корневую папку с музыкой. Без этого плеер не сможет находить треки. При первом запуске плеер **принудительно выводит окно выбора корневой папки** — настройки и основное окно в это время недоступны, пока папка не будет выбрана. Укажите папку, где хранится вся ваша музыка. После этого кнопка "Открыть папку" 📁 на боковой панели станет активной.

## 3. Основное окно

Окно плеера разделено на несколько областей:

```
┌──────────────────────────────────────────────────────────┐
│ [нота] SonicFlame  [название плейлиста] [сортировка][—][✕]│  ← Заголовок
├──────┬────────────────────────────────┬──────────────────┤
│      │         Обложка                │    Плейлист      │
│      │    (информация о треке)        │  (список треков) │
│      │                                │                  │
├──────┴────────────────────────────────┴──────────────────┤
│  0:00 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 3:45              │  ← Полоса прогресса
│ [📁][🔀] [⏮] [▶] [⏭] [🔁] [🔊] [====] [♡]           │  ← Панель управления
└──────────────────────────────────────────────────────────┘
```

- **Заголовок** — название программы, имя текущего плейлиста, выпадающий список сортировки, кнопки свернуть/закрыть
- **Левая часть (обложка)** — обложка трека с эффектом размытия, название, исполнитель, альбом и звезда настроения
- **Правая часть (плейлист)** — список треков в текущей папке или режиме
- **Полоса прогресса** — текущая позиция воспроизведения, время слева и справа
- **Панель управления** — кнопки и ползунки для управления плеером

Окно можно перетаскивать мышью за область заголовка.

## 4. Воспроизведение

### Выбор папки для прослушивания

1. Нажмите на иконку папки 📁 на боковой панели (слева)
2. Откроется **кастомный проводник** — окно выбора папки с двумя панелями:
   - **Слева** — список «Ключевые папки» (топ-10 папок по количеству треков, а также корневая папка «Вся музыка»)
   - **Справа** — файловое дерево с фильтром поиска, сортировкой (по названию/дате/размеру) и ленивой подгрузкой подпапок
   - **Внизу** — строка с полным путём, количество треков/папок и кнопка «Выбрать»
3. Выберите папку и нажмите «Выбрать» (или дважды кликните по папке в дереве)
4. Плеер отсканирует папку и начнёт воспроизведение

**Скорость загрузки** зависит от количества треков в папке. Папка загружается вместе со всеми вложенными подпапками — можно выбрать корневую музыкальную папку, но загрузка займёт время и создаст нагрузку.

**При первом сканировании** каждый трек извлекается, анализируется и вносится в базу данных — это может занять время.

**При повторных загрузках** (той же папки) плеер проверяет только изменения: новые файлы добавляются, удалённые — убираются. Это происходит практически моментально.

На панели заголовка отображается название текущей папки и количество треков. Во время сканирования в заголовке мигает индикатор статуса.

### Панель управления (снизу)

Все кнопки на панели управления (слева направо):

| Кнопка | Действие |
|--------|----------|
| 📁 **Все песни исполнителя** | Загрузить в плейлист все треки текущего исполнителя |
| 🔀 **Похожие треки** | Найти и загрузить треки похожие на текущий |
| ⏮ **Предыдущий** | Переключиться на предыдущий трек в плейлисте |
| ▶ / ⏸ **Play / Pause** | Запустить или поставить на паузу (с плавным затуханием если включено) |
| ⏭ **Следующий** | Переключиться на следующий трек |
| 🔁 **Повтор** | Режимы: без повтора → повтор всего плейлиста → повтор одного трека |
| 🔊 **Громкость** | Ползунок громкости; нажмите на иконку чтобы быстро выключить/включить звук |
| ♡ **Избранное** | Добавить или убрать текущий трек из избранного |

### Как работает повтор

Нажимайте на кнопку повтора 🔁 чтобы переключать режимы:

- **Обычный цвет** — по окончании плейлиста воспроизведение останавливается
- **Акцентный цвет** — повтор всего плейлиста
- **Акцентный цвет + кружок с цифрой 1** — повтор одного трека

### Полоса прогресса (Seek bar)

- Показывает текущую позицию трека
- Кликните в любом месте полосы — воспроизведение перемотается на это место
- Можно перетаскивать ползунок мышью
- Слева время от начала, справа — общая длительность

### Плавное затухание (Fade)

Если в настройках включено затухание (1–5 с), при нажатии **Play / Pause** громкость плавно увеличивается или уменьшается в течение заданного времени. При выключении паузы громкость восстанавливается с той же скоростью. Значение 0 отключает эффект.

### Возобновление воспроизведения

При запуске плеер автоматически восстанавливает последний играющий трек и позицию воспроизведения (если файл существует).

### Обработка отсутствующих файлов

Если файл текущего трека был удалён с диска, плеер покажет диалог с предложением удалить этот трек из библиотеки. При подтверждении запись удаляется из базы данных и кеша обложек, после чего плеер автоматически переключается на следующий трек.

### Режимы плейлиста

Плеер поддерживает несколько режимов отображения плейлиста. Текущий режим отображается в заголовке окна:

- **Обычная папка** — все треки из выбранной папки
- **Избранное** — только треки, отмеченные сердечком
- **Топ** — топ-100 треков по количеству прослушиваний
- **Похожие треки** — подборка похожих на текущий трек
- **Исполнитель** — все треки выбранного исполнителя

## 5. Плейлист

### Сортировка

В правой части заголовка окна находится выпадающий список с режимами сортировки:

- **По исполнителю** — треки группируются по исполнителям в алфавитном порядке
- **По названию** — треки сортируются по названиям
- **По новизне** — треки сортируются по дате создания файла
- **Перемешать** — треки перемешиваются случайным образом

Режим сортировки запоминается — он сохранится и после перезапуска программы.

### Взаимодействие со списком треков

- **Клик по тексту трека** — начать воспроизведение выбранного трека
- **Клик по сердечку ♡** — добавить/убрать трек из избранного
- **Клик по бейджам** (жанр, длительность, lossless) — открыть редактор тегов для этого трека
- **Клик по обложке** — прокрутить плейлист к текущему играющему треку
- **Правый клик по треку** — контекстное меню:
  - **Найти похожие треки** — подбор треков похожих на выбранный
  - **Все песни исполнителя** — загрузить все треки исполнителя выбранного трека
  - **Редактировать теги** — открыть редактор тегов для выбранного трека
  - Пункты от установленных плагинов (если есть)

### Индикаторы в плейлисте

- **👑 Корона** — трек в Lossless-качестве (FLAC)
- **♡ Сердце** — трек в избранном
- **Жанры** — отображаются до трёх жанров; если их больше, показывается `+N`
- **Акцентный цвет** — выделяет текущий играющий трек

## 6. Боковая панель

Левая узкая панель (42px) содержит кнопки для основных действий:

| Иконка | Назначение | Когда используется |
|--------|-----------|-------------------|
| 📁 | Открыть папку с музыкой | Выбор папки для прослушивания |
| ♡ | Избранное (вкл/выкл режим) | Показать только избранные треки |
| ⭐ | Топ (вкл/выкл режим) | Показать топ-100 треков |
| 📚 | Библиотека | Открыть окно библиотеки (отдельный процесс) |
| ⚙ | Настройки | Открыть диалог настроек |

Иконки активных режимов (Избранное, Топ) подсвечиваются акцентным цветом. Повторное нажатие выключает режим и возвращает обычный плейлист.

> **Важно**: Одновременно может быть активен только один режим (Избранное или Топ). Включение одного выключает другой.

## 7. Обложка и информация о треке

В левой части окна отображается обложка текущего трека.

### Эффекты

- **Ambient blur** — размытая копия обложки служит фоном, создавая эффект свечения
- **Чёткая обложка** — накладывается поверх размытого фона с полупрозрачностью
- **Градиентная тень** — плавный переход от обложки к чёрному фону

### Звезда настроения ★

Над обложкой отображается звезда, цвет которой отражает характеристики трека:

| Ось | Что измеряет | Визуализация |
|-----|-------------|--------------|
| **Темп (BPM)** | Скорость трека | Медленный → зелёный, средний → оранжевый, быстрый → красный |
| **Энергия** | Плотность и интенсивность звука | Влияет на насыщенность цвета |
| **Настроение** | Яркость/тембр звука (спектральный центр) | Влияет на яркость цвета |

Звезда — это **индикатор проанализированного трека**. Если звезда есть — трек проанализирован и может участвовать в подборе похожих. Если нет — значит трек ещё не проанализирован (см. раздел [Анализ аудио](#8-анализ-аудио)).

> **Важно**: Звезда появляется только при загрузке/перезагрузке плейлиста. Если трек был проанализирован во время воспроизведения, звезда на обложке появится после переключения на другой трек и обратно, или после перезагрузки папки. Данные анализа статичны и обновляются при каждой загрузке плейлиста.

### Информация о треке

Под обложкой отображаются:

- **Название трека** — акцентным цветом, жирным шрифтом
- **Исполнитель** — белым, жирным шрифтом
- **Альбом** — серым шрифтом

## 8. Анализ аудио

Для работы подбора похожих треков (кнопка 🔀 на панели управления) и отображения звезды настроения каждый трек должен пройти аудиоанализ.

### Как это работает

Анализ выполняется библиотекой **librosa** — она извлекает из аудио 6 характеристик:

1. **Темп (BPM)** — скорость трека
2. **Энергия** — плотность и интенсивность звука
3. **Настроение (mood)** — яркость/тембр звука (спектральный центр)
4. **Zero-crossing rate** — «шумность» трека
5. **Spectral flux** — изменчивость звуковой картины
6. **HPSS ratio** — соотношение ритмической и мелодической составляющих

Эти характеристики сравниваются между треками. Чем ближе значения — тем выше вероятность, что треки похожи по звучанию. Дополнительно учитывается жанр (точное совпадение или совпадение по группе жанров).

### Когда включается анализ

Анализ запускается **в фоне** при сканировании папки. Он выполняется параллельно для каждого нового трека. Программа не ждёт завершения анализа — вы можете слушать музыку пока треки обрабатываются.

### Почему треки не выпадают в «Похожих»?

Самая частая причина — **трек не проанализирован**. Проверить это можно по звезде настроения ★ на обложке трека:

- **Звезда есть** → трек проанализирован, может участвовать в подборе
- **Звезды нет** → трек ещё не проанализирован, в подборе участвовать не будет

Если анализ не включается — проверьте в Настройки → Главная → **Длительность анализа** (должно быть > 0). Для больших библиотек увеличьте **Точность подбора** и убедитесь, что выбран адекватный **Фильтр языка** (см. раздел [Настройки — Главная](#111-главная-main)).

### Нагрузка на систему

Анализ аудио может потреблять **до 5 ГБ оперативной памяти** и до **80% свободных ресурсов процессора**. При этом программа **не должна тормозить ваш компьютер**, потому что:
- Используются только **свободные в данный момент** ресурсы
- Если другое приложение запрашивает память или процессор — ОС перераспределяет ресурсы
- Анализ выполняется в фоновом потоке с низким приоритетом

Чем короче установлена длительность анализа (30 с вместо 60 с), тем меньше ресурсов потребуется.

## 9. Библиотека

Библиотека открывается в отдельном окне (запускается как субпроцесс). Нажмите на иконку 📚 на боковой панели.

### Вкладки

Библиотека состоит из двух вкладок:

#### Треки

Таблица со всеми треками в вашей коллекции. Поддерживает:

- **Пагинация** — треки загружаются порциями по 250 штук для быстрой работы
- **Поиск** — строка поиска для фильтрации по названию, исполнителю, альбому
- **Фильтр по жанру** — выпадающий список всех жанров
- **Фильтр "Только избранное"** — галочка для показа только избранных треков

В таблице отображаются колонки:
Название, Исполнитель, Альбом, Жанр, Папка, Длительность, Битрейт, ★ (звезда настроения), Прослушивания, ♡ (избранное).

Действия в таблице:
- **Двойной клик по треку** — воспроизвести (через IPC передаётся команда плееру)
- **Клик правой кнопкой** — открыть контекстное меню (редактор тегов, открыть папку, удалить)

#### Исполнители

Сетка карточек исполнителей. Каждая карточка содержит:
- Коллаж из 4 обложек треков этого исполнителя
- Имя исполнителя
- Количество треков

При наведении карточка подсвечивается акцентным цветом. Клик по карточке воспроизводит все треки исполнителя.

### Синхронизация с плеером

Библиотека автоматически обновляется при изменении базы данных (после сканирования папок, редактирования тегов и т.д.). При изменении акцентного цвета в плеере он автоматически применяется и в библиотеке.

## 10. Редактор тегов

Редактор тегов открывается кликом по бейджам трека в плейлисте (жанр, длительность, корона lossless).

### Редактирование

Вы можете изменить следующие поля:
- **Название** (Title)
- **Исполнитель** (Artist)
- **Альбом** (Album)
- **Жанр** (Genre) — разделители: `;`, `,`, `/`
- **Год** (Year)
- **Номер трека** (Track Number)

### Поиск информации онлайн

Нажмите кнопку "Найти в интернете" чтобы автоматически подобрать метаданные через iTunes и Deezer. Если найдено несколько вариантов, выберите подходящий из списка.

### Управление обложками

- **Загрузить с диска** — выберите изображение на компьютере (диалог открывается в папке трека)
- **Искать онлайн** — поиск обложек через iTunes и Deezer
- **Сгенерировать** — создаёт абстрактную обложку на основе фонового изображения

Если обложка отсутствует, редактор предложит искать её в интернете (откроет Google Images).

### Сохранение

Все изменения сохраняются в фоновом потоке (интерфейс не блокируется). Во время сохранения отображается анимация загрузки. Поддерживаются форматы MP3 (ID3), FLAC (Vorbis) и M4A/MP4.

### Дополнительные функции

- **Переименовать файл из тегов** — имя файла синхронизируется с заполненными полями
- **Переместить трек** — переместить аудиофайл в другую папку
- **Удалить трек** — удалить файл с диска и из библиотеки

После сохранения воспроизведение текущего трека перезапускается с сохранением позиции (если редактировался играющий трек).

## 11. Настройки

Нажмите на шестерёнку ⚙ на боковой панели, чтобы открыть настройки. Они разделены на 6 страниц.

### 11.1 Главная (Main)

**Корневая папка с музыкой**

Укажите папку, где хранится ваша музыка. Это корневая директория для поиска и ограничение для безопасности (плеер не даст перемещать треки за её пределы). Если папка не задана — кнопка "Открыть папку" на боковой панели будет неактивна.

**Затухание при паузе/воспроизведении (Fade)**

Ползунок 0–5 секунд. Определяет длительность плавного изменения громкости при нажатии Play и Pause. Значение 0 отключает эффект (громкость меняется мгновенно).

**Точность подбора похожих треков**

Ползунок от 0 до 40. Чем выше значение, тем строже отбор — вы получите меньше, но более похожих треков. Чем больше у вас библиотека, тем выше можно ставить точность.

**Длительность анализа треков**

Ползунок 30–60 секунд. Определяет, сколько секунд трека анализируется для извлечения аудиохарактеристик. Больше = точнее, но дольше и больше нагрузка на систему.

**Максимум похожих треков**

Ползунок 50–200 (шаг 10). Ограничивает количество треков в подборке «Похожие треки». По умолчанию 100.

**Фильтр языка**

Три режима:
- **Не учитывать** — язык не влияет на подбор похожих треков
- **Понижать вес** — треки на другом языке получают пониженный рейтинг похожести
- **Исключать** — треки на другом языке полностью исключаются из результатов

**Удалить базу данных**

Сбрасывает всю библиотеку (переименовывает текущий файл БД в backup.db, очищает кеш обложек). После этого потребуется повторное сканирование папок.

### 11.2 Внешний вид (Appearance)

**Акцентный цвет**

15 предустановленных цветов. Выбор меняет цветовую схему всего приложения: кнопки, слайдеры, выделение, заголовки.

**Динамический цвет из обложки**

Если включено, акцентный цвет автоматически подстраивается под доминирующий цвет обложки текущего трека.

**Мини-плеер при сворачивании**

Включает отображение маленького плеера (480×60px) в правом нижнем углу экрана при сворачивании в трей.

**Прозрачность мини-плеера**

Регулирует, насколько прозрачным будет мини-плеер, когда на него не наведён курсор.

### 11.3 Веб-сервер (Web Server)

**Включить веб-сервер**

Запускает локальный HTTP-сервер для управления плеером из браузера или Android-приложения.

**Порт**

Номер порта (по умолчанию 8080). Доступные значения: 1024–65535 (запрещены 21, 22, 80, 443).

**QR-код**

Отображает QR-код с адресом сервера для быстрого подключения с телефона.

**Удалённое закрытие**

Если включено, позволяет закрыть программу через веб-интерфейс или Android-приложение.

> **Подсказка**: После включения сервера откройте браузер на телефоне (в одной сети с компьютером) и отсканируйте QR-код, чтобы управлять плеером.

### 11.4 Система (System)

**Блокировать сон**

Предотвращает переход компьютера в спящий режим во время воспроизведения.

**Устройство вывода звука**

Позволяет выбрать конкретное аудиоустройство (наушники, колонки). При отключении выбранного устройства плеер автоматически переключается на системное устройство по умолчанию. Когда устройство снова появляется — плеер переключается обратно.

**Таймер автовыключения**

Автоматически закрывает программу при простое (пауза/стоп) через выбранное время. Доступные интервалы: 15 мин, 30 мин, 1 час, 3 часа, 6 часов, 12 часов. "Никогда" — не выключать.

**Очистка базы данных от отсутствующих файлов**

Удаляет из библиотеки записи о треках, файлы которых были удалены с диска. Нажмите кнопку — после завершения она покажет количество удалённых записей.

### 11.5 О программе (About)

Информация о версии приложения и версии базы данных. Регистрация программы (опционально). Ссылки на GitHub и сайт проекта.

### 11.6 Плагины (Plugins)

Список установленных плагинов с возможностью включения/выключения без перезапуска приложения. Каждый плагин может добавлять кнопки на боковую панель, пункты в контекстное меню плейлиста, собственные вкладки настроек или кастомный виджет. По умолчанию все плагины отключены — для активации переключите тумблер рядом с названием плагина.

## 12. Веб-сервер и удалённое управление

### Веб-интерфейс

После включения веб-сервера (Настройки → Веб-сервер) откройте в браузере `http://IP_КОМПЬЮТЕРА:8080`.

Веб-интерфейс показывает:
- Обложку текущего трека
- Название, исполнителя, альбом
- Полосу прогресса
- Плейлист (можно прокручивать и выбирать треки)
- Кнопки управления

Интерфейс адаптирован для мобильных устройств.

### REST API

Веб-сервер предоставляет HTTP API для программного управления плеером. Это позволяет интегрировать плеер с любыми системами умного дома, скриптами и т.д.

### Android-приложение

Скачайте приложение с [sonicflame.pro](https://sonicflame.pro). Возможности:
- Воспроизведение/пауза, следующий/предыдущий трек
- Регулировка громкости и перемотка
- Режимы повтора
- Избранное
- Плейлисты: папки, Избранное, Топ, Похожие, все треки исполнителя
- Подключение по QR-коду или вручную

### Безопасность

- Доступ к веб-серверу разрешён только с локальных/приватных IP-адресов
- Добавлены стандартные заголовки безопасности
- Полные пути к файлам не раскрываются

## 13. Системные медиа-клавиши

Плеер поддерживает глобальные медиа-клавиши Windows:

| Клавиша | Действие |
|---------|----------|
| Play/Pause | Воспроизведение / Пауза |
| Next | Следующий трек |
| Previous | Предыдущий трек |

Клавиши работают даже когда окно плеера свёрнуто в трей или не в фокусе.

Также поддерживается интеграция с **SMTC** (System Media Transport Controls) — медиа-панель Windows, которая отображается в оверлее поверх других приложений и на экране блокировки.

## 14. Системный трей и мини-плеер

### Иконка в трее

При запуске в системном трее (рядом с часами) появляется иконка плеера. Контекстное меню:
- **Показать** — развернуть окно плеера
- **Выход** — закрыть программу

### Сворачивание в трей

Если в настройках включён "Мини-плеер при сворачивании", то при нажатии "Свернуть" окно плеера скрывается в трей и появляется мини-плеер.

### Мини-плеер

Маленькое окошко (480×60px) в правом нижнем углу экрана:
- Всегда поверх других окон
- Можно перетаскивать мышью (за область названия трека)
- Содержит: ▶/⏸, ⏮, ⏭, развернуть, название трека и исполнителя
- Прозрачный когда на него не наведён курсор (прозрачность настраивается)
- Становится непрозрачным при наведении

## 15. Плагины

Плеер поддерживает расширение функционала через плагины — сторонние модули, добавляющие новые возможности. Плагины располагаются в папке `plugins/` рядом с `main.py` (или исполняемым файлом).

### Установка плагина

1. Скачайте папку плагина (например, `my_plugin/`) или создайте свою
2. Поместите её в папку `plugins/` рядом с программой
3. В каждом плагине должен быть файл `plugin.json` с описанием и папка `__init__.py` с точкой входа
4. Запустите (или перезапустите) программу — плагин появится в Настройки → Плагины

### Включение и настройка

Перейдите в **Настройки ⚙ → Плагины**. Рядом с каждым плагином есть тумблер включения. Если у плагина есть собственные настройки, рядом появится кнопка шестерёнки.

Включение и выключение происходит без перезапуска программы.

### Разработка плагина

Инструкция по разработке плагинов находится в `docs/plugin_developer_manual.md`. Плагин может:

- Добавлять кнопки на боковую панель
- Добавлять пункты в контекстное меню плейлиста
- Добавлять вкладки в диалог настроек
- Предоставлять собственный виджет настроек
- Получать доступ к плееру, плейлисту и библиотеке через PluginHub
- Сохранять свои данные в отдельной папке `plugins/<имя>/`

## 16. Часто задаваемые вопросы

### Как добавить музыку?

Укажите корневую папку в настройках (⚙ → Главная), затем нажмите на иконку папки 📁 на боковой панели и выберите нужную подпапку.

### Почему звезда настроения не отображается?

Звезда ★ отображается только для проанализированных треков. Если трек новый — дождитесь завершения фонового анализа. Звезда появится после перезагрузки плейлиста (переключитесь на другой трек и обратно, либо перезагрузите папку). Количество проанализированных треков показывается в настройках (⚙ → Главная) в скобках рядом с общим числом: `7500 (7500)` — все треки проанализированы.

### Почему в «Похожих треках» нет результата?

Основные причины:
1. **Текущий трек не проанализирован** — на нём нет звезды ★. Подождите окончания анализа или перезагрузите папку.
2. **Слишком высокая точность подбора** — попробуйте снизить в Настройки → Главная → Точность подбора.
3. **Фильтр языка исключает все треки** — проверьте режим фильтра языка в настройках.
4. **Слишком мало проанализированных треков в библиотеке** — подбор работает только по проанализированным трекам.

### Почему долго загружается папка?

Папка загружается вместе со всеми вложенными подпапками. Если вы выбрали корневую музыкальную папку с тысячами треков — это займёт время. При первом сканировании каждый трек извлекается и вносится в базу. Повторные загрузки той же папки будут практически мгновенными.

### Как сбросить все настройки?

Удалите папку `.cache` рядом с исполняемым файлом. Все настройки, база данных и кеш обложек будут сброшены.

### Почему плеер не видит некоторые файлы?

Плеер поддерживает MP3, FLAC, M4A и MP4. Файлы должны быть не повреждены. После добавления новых файлов в уже просканированную папку перезапустите сканирование — изменения будут обнаружены автоматически.

### Как управлять плеером с телефона?

1. Включите веб-сервер в настройках (⚙ → Веб-сервер → Включить)
2. Откройте QR-код на той же странице
3. Установите Android-приложение с сайта проекта
4. Отсканируйте QR-код приложением
5. Телефон и компьютер должны быть в одной Wi-Fi сети

### Можно ли использовать плеер в качестве сервера?

Нет, плеер не предназначен для потоковой передачи аудио на другие устройства. Веб-сервер и Android-приложение предназначены только для управления воспроизведением на том же компьютере.

### Почему не работают плагины?

Проверьте, что папка плагина находится в `plugins/` рядом с программой и содержит `plugin.json` и `__init__.py`. После добавления нового плагина может потребоваться перезапуск программы. Убедитесь, что версия плеера подходит для этого плагина (информация о совместимости указана в описании плагина в настройках).
