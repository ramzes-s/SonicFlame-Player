### 1. Первый запуск и добавление музыки

При первом запуске плеера ваш плейлист будет пуст. Чтобы добавить музыку, воспользуйтесь иконкой папки (📁) на боковой панели слева или в нижней панели управления.

- **Выберите корневую папку:** Укажите папку, в которой хранится вся ваша музыка. Плеер просканирует ее (включая все вложенные папки) и добавит все найденные треки в свою библиотеку.
- **Подождите:** Первое сканирование может занять некоторое время, если у вас большая коллекция. Вверху окна будет отображаться статус сканирования.
- **Готово:** После завершения сканирования треки появятся в плейлисте, и начнется воспроизведение.

В дальнейшем вы можете быстро переключаться между папками, используя тот же значок папки.

### 2. Главное окно

Интерфейс плеера состоит из нескольких основных зон.

#### Элементы управления
Панель в нижней части окна содержит все необходимое для управления воспроизведением:
- **Полоса прокрутки (Seek Bar):** Показывает прогресс текущего трека. Вы можете нажать на любое место, чтобы перемотать.
- **Кнопки управления:**
    - **Shuffle (🔀):** Перемешивает текущий плейлист.
    - **Previous (⏮):** Предыдущий трек.
    - **Play/Pause (▶/⏸):** Начать или приостановить воспроизведение.
    - **Next (⏭):** Следующий трек.
    - **Repeat (🔁):** Управляет режимом повтора (не повторять, повторить весь плейлист, повторить один трек).
- **Громкость:** Нажмите на иконку динамика, чтобы выключить звук, или используйте ползунок для регулировки громкости.
- **Избранное (♡):** Добавляет или убирает текущий трек из списка избранных.

#### Боковая панель
Вертикальная панель слева предоставляет быстрый доступ к основным функциям:
- **Открыть папку (📁):** Открывает диалог выбора папки с музыкой.
- **Избранное (♡):** Отображает в плейлисте только треки, добавленные в избранное.
- **Топ треков (⭐):** Показывает 50 самых прослушиваемых треков.
- **Настройки (⚙):** Открывает окно настроек плеера.
- **Библиотека (📚):** Открывает большое окно библиотеки для удобной работы со всей коллекцией.

#### Плейлист
Справа от обложки находится список треков в текущей папке или режиме (избранное, топ).
- **Воспроизведение:** Клик по треку начнет его воспроизведение.
- **Сортировка:** В правом верхнем углу окна (рядом с кнопками управления окном) находится выпадающий список для сортировки треков: по исполнителю, названию, новизне или в случайном порядке.
- **Контекстная информация:** На каждом треке отображаются значки: корона (👑) для lossless-форматов (FLAC) и сердце (♥) для треков в избранном. Жанры, Клик по жанрам трека открывает редактор тегов.

### 3. Библиотека

Окно библиотеки (📚) — ваш центр управления всей музыкальной коллекцией. Оно имеет две вкладки.

#### Вкладка "Треки"
Представляет всю вашу музыку в виде таблицы с мощными инструментами фильтрации:
- **Поиск:** Строка поиска вверху позволяет мгновенно найти треки по названию, исполнителю или альбому.
- **Фильтры:** Вы можете отфильтровать список по конкретной папке или жанру с помощью выпадающих списков.
- **Контекстное меню:** Клик правой кнопкой мыши по треку открывает меню с действиями: "Воспроизвести", "Воспроизвести Артиста", "Редактировать теги", "Открыть в проводнике".
- **Звезда настроения (★):** Цвет звезды показывает эмоциональную окраску трека, определенную после аудио-анализа.

#### Вкладка "Исполнители"
Это визуальное представление вашей фонотеки:
- **Карточки исполнителей:** Каждый исполнитель представлен в виде карточки с коллажом из обложек его альбомов.
- **Быстрый запуск:** Клик по карточке исполнителя немедленно загружает все его треки в основной плейлист.
- **Первая загрузка:** При первом открытии этой вкладки плееру может потребоваться некоторое время для анализа библиотеки и создания коллажей. В дальнейшем данные будут загружаться из кеша.

### 4. Редактор тегов
Вы можете открыть редактор, кликнув на бейджи жанров в плейлисте или через контекстное меню в библиотеке.
- **Редактирование:** Изменяйте название, исполнителя, альбом, год, жанр и номер трека.
- **Работа с обложкой:**
    - **Загрузить обложку:** Выбрать файл с картинкой на вашем компьютере.
    - **Поиск обложки:** Плеер автоматически найдет и предложит варианты обложек из интернета.
- **Поиск информации:** Кнопка "Поиск информации о треке" автоматически заполнит все поля на основе данных из онлайн-сервисов.
- **Имя файла:** Вы можете сгенерировать имя файла из тегов (`Артист - Название.mp3`) или наоборот — заполнить теги из имени файла.
- **Удаление трека:** Кнопка "Удалить" позволяет полностью стереть трек из плеера, базы данных, а также **безвозвратно удалить файл с диска** (после подтверждения в диалоговом окне).

### 5. Настройки

Окно настроек (⚙) позволяет персонализировать плеер:
- **Акцентный цвет:** Выберите один из 14 пресетов, который будет использоваться во всем интерфейсе.
- **Динамический цвет:** Если включить, цвет интерфейса будет автоматически подстраиваться под обложку текущего трека.
- **Корневая папка:** Здесь можно изменить основную папку с вашей музыкой.
- **Мини-виджет:** Включите опцию "Включать виджет при сворачивании", и при сворачивании основного окна в правом нижнем углу экрана появится удобный мини-плеер.
- **Веб-сервер:** Здесь можно включить или выключить веб-интерфейс и изменить его порт.

### 6. Веб-интерфейс для удаленного управления

Если веб-сервер включен в настройках (например, на порту `8080`), вы можете управлять плеером с любого устройства в вашей локальной сети (например, с телефона).
- **Доступ:** Откройте браузер на телефоне и введите `http://<IP-адрес-компьютера>:<порт>`. Например: `http://192.168.1.5:8080`.
- **QR-код:** В настройках плеера рядом с полем порта есть кнопка для отображения QR-кода. Просто отсканируйте его камерой телефона, чтобы быстро открыть веб-интерфейс.
- **Возможности:** Веб-интерфейс позволяет видеть текущий трек, управлять воспроизведением, громкостью и выбирать треки из плейлиста.
